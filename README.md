# Prof. Haque's Administrative Law Walkthroughs (public beta)

A scroll-based introduction to administrative law through one running example, the COPPA statute and the FTC, and one mechanical analogy: gears, belts, and blocks. Seven short walkthroughs, practice questions, and an interactive simulation.

This is the public beta. Nothing is recorded; progress is kept only in your own browser. Feedback is welcome at haquer@wfu.edu.
